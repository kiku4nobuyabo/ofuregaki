# 御触書工房 v0.1

「信長の野望・真戦」の御触書原稿をつくる、非公式の静的Webアプリです。
タイトル・本文を編集し、完成イメージを見ながら、ゲーム貼付用テキストをコピーできます。
ログイン・インストール・ビルドは不要です。

## まず動かす（Windows / Mac）

1. ZIPを**すべて解凍**します。ZIPの中から直接開かないでください。
2. `ofuregaki-v0.1` フォルダの **`index.html` をダブルクリック**します。
3. Chrome・Edge・Safariなどのブラウザで開きます。
4. タイトルと本文を入力すると、左側（スマホでは上側）に完成イメージが出ます。

WindowsでHTMLの関連付けが別アプリになっている場合は、`index.html` を右クリック →「プログラムから開く」→ Chrome / Edge を選んでください。
`index.html` だけを別の場所に移動しないでください。`css`・`js`・`data`・`assets` フォルダが隣に必要です。

スマートフォンでの利用には、下記の方法で静的サイトへ配置し、URLを開く方法を推奨します。
ファイルを直接開いた場合の保存領域はブラウザ依存です。同じフォルダ・同じブラウザで使ってください。
保存が許可されない環境では画面にエラーが出ます。公開したURLで保存した内容と、ローカルで保存した内容も別々です。

開発用にHTTPで確認する場合は、このフォルダで `python -m http.server 8000` を実行して `http://localhost:8000` を開くこともできます。アプリ自体にPythonは必要ありません。

## 使い方

1. タイトル・本文を入力します。本文はプレーンテキストです。
2. 文字を選んで「赤」「青」「橙」「緑」を押すと色構文で囲まれます。未選択なら記号が入り、その間に入力できます。
3. 「スタンプ」「座標」から挿入できます。元のカーソル位置、または選択範囲へ入ります。
4. プレビューで色・改行・折り返しを確認します。
5. **「ゲーム貼付用をコピー」は本文をコピー**します。タイトルは隣の「タイトルをコピー」で別にコピーします。動画のゲーム編集画面が別欄だったため、この方式にしています。
6. 原稿を権限者へ渡すか、ゲームの対応欄へ貼り付けてください。本ツールから投稿はしません。

ブラウザにコピーを拒否された場合は、手動コピー用の画面を表示します。PCはCtrl+C（MacはCommand+C）、スマホは長押しでコピーしてください。

### 改行と構文

|機能|本文へ入力する形式|
|---|---|
|赤|`&文字&`|
|青|`@文字@`|
|橙|`#文字#`|
|緑|`$文字$`|
|座標|`1209,578` または `よど城 422,1559`|
|スタンプ|`{13}`|
|改行|Enter。ゲーム形式の `\n` を貼り付けても変換します。|

内部・下書き保存時の改行は実際のLFです。コピー時は、動画で使われていた**バックスラッシュとnの2文字 `\n`**へ変換します。
「コピーする形式を確認」を開くと、出力を見ることができ、「実際の改行」へ切り替えられます。
変換処理は `js/newlines.js` に独立しています。初期モードは `js/config.js` の `defaultNewlineMode` で変更できます。
文字としてのバックスラッシュ+nも改行になります。リテラル `\n` を残すエスケープ規則は、ゲーム側の仕様が不明なため設けていません。

色記号の閉じ忘れは警告だけを出します。閉じていない最後の記号は、プレビューでも通常文字として残します。コピー内容は勝手に修正しません。
色指定の入れ子・交差はゲーム側の挙動が未確認です。重なった指定は警告し、記号を含めた通常文字で表示します。
同じ色の閉じ記号は出現順に2つずつ組み合わせます。既存の色指定全体を選択し直した場合は、その指定を新しい色に置き換えます。

座標は半角の非負整数2つと半角カンマを認識します。座標範囲は未確認のため上限チェックをしません。
小数・負数・3つ以上のカンマ区切り・全角数字・全角カンマは対象外です。座標は下線表示のみで、ゲーム地図へ移動しません。

## 下書き・マイテンプレート

- それぞれ別の領域へ最大10件保存できます。
- 保存名を入力して「保存」を押します。編集中原稿の自動保存はしません。
- 保存したものは「読込」「削除」ができます。削除には確認があります。
- 読み込み時、現在のタイトルか本文が入っていれば置き換えを確認します。
- 読込／保存した項目と同じ保存名・保存先で保存すると、確認後にその項目を上書きします。名前を変えれば別件として保存します。
- 同じ名前でも別の原稿から新規保存した項目は独立したIDを持ちます。名前の一致だけでは無断上書きしません。
- 10件になったら新規保存を止め、不要なものの削除を案内します。既存項目の上書きは可能です。
- 未保存の変更があるままページを離れる場合は、ブラウザに確認を要求します。ただしモバイルの強制終了などでは確認が出ないことがあります。必要な原稿は保存ボタンで保存してください。

下書き・マイテンプレは、**この端末・このブラウザに保存**されます。別端末には同期されません。ブラウザのデータを削除すると消えます。
保存容量不足・保存禁止・読み込めない保存データはエラー表示します。壊れたデータを勝手に空データで置き換えません。

## Webへ配置する（GitHub Pages等）

公開に必要なのは次のファイル・フォルダです。**中身をそのまま、階層を変えずにアップロード**してください。

```text
index.html
css/
js/
data/
assets/
.nojekyll
```

README・docs・testsは説明／確認用なので、公開しなくても動作します。元の参考動画や、個人の御触書データはZIPに含めていません。

### GitHub Pagesの例

1. GitHubでサイト用のリポジトリを用意します。
2. `Add file` → `Upload files` を選び、解凍した**フォルダの中身**をアップロードしてコミットします。リポジトリの一番上に `index.html` がある状態にします。
3. リポジトリの `Settings` → `Pages` を開きます。
4. `Build and deployment` の `Source` を `Deploy from a branch` にします。
5. `Branch` をアップロード先（通常 `main`）、フォルダを `/(root)` にして `Save` します。
6. 公開処理が終わったら、同じ画面に表示されるURLを開きます。

ビルドコマンド、Node.js、npm、サーバー設定は不要です。相対パスなのでリポジトリ名を含むサブディレクトリでも動作します。
更新時は変更したファイルを同じ場所へアップロードします。共通テンプレも更新後の再読み込みで反映されます。古い表示が続く場合は再読み込み（PCではCtrl+F5）してください。

このアプリにはアクセス制限がありません。公開URLにアクセスできる人は利用できます。一門共通テンプレの定義も公開ファイルに含まれます。非公開にしたい場合はアクセス制限を用意できる静的ホスティングを選んでください。

公式手順（2026-09-29確認）:
- https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
- https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## スタンプ画像を追加・差し替え

1. PNGなどの画像を `assets/stamps/` に置きます。例：`13.png`。
2. `data/stamps.js` をUTF-8対応のテキストエディタで開きます。
3. 該当IDの `imagePath` を変更します。

```js
{ id: 13, label: '不安', fallbackEmoji: '😟', imagePath: 'assets/stamps/13.png' },
```

エディタ本体の変更は不要です。パレットと本文プレビューが同じ定義を参照します。
画像の読み込み失敗時は `fallbackEmoji` を表示します。ゲームへコピーする文字列は画像に関係なく `{13}` のままです。
画像はローカルの `assets/stamps/` 以下のPNG・WebP・GIF・JPEGに対応します。ファイル名は半角英数字・ハイフン・アンダースコアを使用してください。外部URLは読み込みません。
画像は正方形・透明背景の64〜128px程度が扱いやすいです。

新しいIDを追加する場合は同じ形式の行を配列へ追加します。IDを重複させないでください。
未登録の `{数字}` も入力でき、IDのまま表示・コピーします。

v0.1は動画で入力されたID 1〜56を用意し、パレットの並びから近いUnicode絵文字を仮対応させています。**個々のIDと絵柄の対応・画像寸法は実機での照合が必要**です。仮絵文字を正確なゲーム画像とは扱わないでください。

## 一門共通テンプレを追加・編集

`data/common-templates.js` を編集します。v0.1は空の配列です。動画のゲーム公式見本は収録していません。

```js
Ofuregaki.commonTemplates = [
  {
    id: 'my-clan-template-01',
    name: 'ここにテンプレート名',
    title: 'ここに御触書のタイトル',
    body: 'ここに本文を入力\n&ここは赤色&'
  }
];
```

この例は**定義形式の説明**であり、アプリには登録していません。
JSの文字列内の `\n` は実際の改行になります。複数追加する場合は、オブジェクトをカンマで区切り、IDは固有にします。
文字列を囲む `'` を本文内で使用する場合は `\'` と書きます。ChatGPTへこのファイルと希望する内容を渡して編集してもらう方法でも構いません。
更新したファイルをサイトへ再配置すると、全利用者が再読み込み時に新しい内容を利用できます。
既にマイテンプレとして保存したコピーには、自動で上書きしません。

## localStorageのキー・データ構造

|キー|内容|上限|
|---|---|---|
|`ofuregaki.v1.drafts`|下書き|10件|
|`ofuregaki.v1.templates`|マイテンプレ|10件|

両方とも、次の形式のJSON文字列です。共通テンプレ・編集中原稿・コピー形式はlocalStorageへ保存しません。

```json
{
  "schemaVersion": 1,
  "items": [
    {
      "id": "ブラウザ内で生成する固有ID",
      "name": "任意の保存名",
      "title": "御触書のタイトル",
      "body": "本文1行目\n本文2行目",
      "savedAt": "2026-09-29T06:00:00.000Z"
    }
  ]
}
```

`savedAt` はUTCのISO形式で、画面上は端末の現地時刻で表示します。`body` の改行はJSON表記では `\n`、JSONを読み込んだ文字列では実際のLFです。
バージョン違い・JSON破損・必須フィールド欠落などがあると、その保存先への操作を停止します。他の保存先とは独立しています。

## 安全性と通信

- ユーザーの入力をHTMLとして解釈しません。プレビュー・保存名・タイトルはテキストノードで描画します。
- 外部ライブラリ、CDN、外部フォント、解析ツール、広告、API通信を使用しません。
- `fetch` / XHR / WebSocket / sendBeacon 等は使用しません。
- CSPの `connect-src 'none'` と `form-action 'none'` でも外部送信を制限します。
- ホスティング先は静的ファイルを配信します。御触書本文・下書き・マイテンプレ・利用履歴を送信するコードはありません。
- 外部画像URLはスタンプに設定できません。画像は配布ファイルとして同梱してください。

## v0.1の限界

プレビューは動画を元にした近似で、実際のゲームへ投稿する検証は行っていません。文字数上限・タイトル上限が未確認なので、仮の制限は設けていません。
端末内の日本語フォント・句読点の禁則処理・スタンプの幅により、折り返しが多少変わります。PCとスマホで本文のレイアウト幅は共通とし、狭い画面では用紙全体を縮小します。
色の厳密な値、座標の装飾、スタンプの対応は仮設定です。実機で確認できたら、上記の分離した定義から調整できます。

自動検証を再実行する開発者は、Node.jsで `node tests/core.test.cjs` を実行できます。`tests/viewport.html` は幅390pxと320pxでの見た目を並べて確認する補助ページです。スマホ実機のOS・キーボード・クリップボードを再現するものではありません。

`package.json`・`package-lock.json`・`vite.config.mjs` は開発時のプレビュー用です。必要な開発者だけが `npm ci` → `npm run dev` で使用します。通常の利用・静的公開にnpmやViteは不要で、これら3ファイルを公開先に置く必要もありません。
