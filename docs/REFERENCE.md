# ゲーム画面との照合・表示仕様

更新日：2026-09-29。

御触書工房のプレビューは、ゲームのPC表示とスマートフォン実機の縦・横表示を比較して調整しています。ゲーム画像そのものや登場人物の画像は配布物に含めず、原稿確認に必要なレイアウトだけをCSSで近似しています。

## 確認済みの入力仕様

- タイトル上限：10文字。
- 本文上限：1000文字。
- 色指定：赤 `&文字&`、青 `@文字@`、橙 `#文字#`、緑 `$文字$`。
- ゲーム用スタンプ：`{数字}`。工房ではID 1〜145を一覧化。
- 通常のUnicode絵文字は御触書へ直接入力できない。絵文字を使う場合はゲーム用スタンプを使用する。
- 座標は `123,456` の形式を認識し、ゲーム表示では位置情報として装飾される。工房ではプレビュー上だけ `📍(123,456)` とし、原稿・コピー文字列は変更しない。
- 改行はEnterによる実改行と、ゲーム入力で使うリテラル `\n` の両方を工房内で扱える。

## 端末別プレビュー

同一の御触書をスマートフォンの縦向き・横向きで比較し、折り返し幅が端末の向きによって変化することを確認しています。

|表示|目安|
|---|---|
|PC|PC表示資料を基準にした幅|
|スマホ縦|全角 約18文字／行|
|スマホ横|全角 約19文字／行|

これは文章の内容を書き換える機能ではなく、同じ原稿を異なる表示幅で確認するための切替です。端末フォント、禁則処理、スタンプ幅などにより実ゲームと完全には一致しません。

## スタンプ

IDとプレビュー用の絵柄は分離しています。ゲームへコピーする文字列は常に `{ID}` で、代替絵文字や将来の画像差し替えによって変化しません。

v0.2公開後に全スタンプ一覧を実機で確認し、ID 9・35・36の代替絵文字対応を修正しました。

- `{9}`：v0.2で `{35}` に表示していた絵柄
- `{35}`：v0.2で `{36}` に表示していた絵柄
- `{36}`：v0.2で `{9}` に表示していた絵柄

現在はUnicode絵文字を代替表示として使用しています。ゲーム内スタンプ画像そのものではないため、表情や細部は一致しない場合があります。正式な画像素材を用意する場合は `data/stamps.js` の `imagePath` だけで差し替えられます。

## 意図的に近似のままにしているもの

- ゲーム固有フォント。
- 色の正確なRGB値。
- 端末やOSごとの微細な文字幅・禁則処理。
- 色構文を入れ子・交差させた場合のゲーム側の優先順位。

未確認事項を推測して自動補正せず、原稿文字列を勝手に変更しない方針です。
