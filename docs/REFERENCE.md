# 参考動画から反映した内容

確認した資料：添付の「画面録画 2026-09-29 143822(1).mp4」。長さ約138.7秒、1174×664px。
全体を8秒間隔で抽出して流れを確認し、文字・編集欄・パレット・完成表示を個別の原寸フレームで確認しました。原動画・切り出し画像は納品ZIPに含めていません。

## 観察と設計への反映

|観察|実装への反映|
|---|---|

## 意図的に断定していない事項

- 動画だけで完成表示を確認できないスタンプIDと個別の絵柄の対応。
- 任意の色構文が入れ子／交差した場合のゲームの優先順位。
- 座標の装飾はv0.2のユーザー指定により、緑色の `📍(X,Y)` として表示。本文やコピーは変更しない。
- ゲーム固有フォント、色の正確なRGB、端末ごとの表示倍率。
- 改行形式が各ゲーム環境で受け入れられるか、本文・タイトルの文字数制限。

ゲーム画像そのものや登場人物の肖像は同梱せず、機能上必要なレイアウトを近似しています。

## v0.2のスタンプ全件化

70〜81秒付近のパレットを追加確認しました。12列×12行の全行と、末尾の「禁」1件を数え、全145件を定義しています。
動画内の入力本文で連続IDを確認できるのは1〜56です。57〜145は同じパレット順で連番として補完しました。末尾は `{145}`。個別IDと実画像の対応はゲーム上の照合結果に応じて `data/stamps.js` だけで修正できます。
標準Unicode絵文字を表示するため、端末やフォントによって見た目や対応状況が異なります。PNG等の素材が用意できたら `imagePath` を設定してください。

これらの開発上の根拠はこの文書で管理し、利用者UIの説明には含めていません。ゲーム公式見本の本文は共通テンプレに転用していません。
