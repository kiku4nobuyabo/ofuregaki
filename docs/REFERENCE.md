## 意図的に断定していない事項

- 動画だけで完成表示を確認できないスタンプIDと個別の絵柄の対応。
- 任意の色構文が入れ子／交差した場合のゲームの優先順位。
- 座標に付く厳密な色・装飾。v0.1は下線で区別。
- ゲーム固有フォント、色の正確なRGB、端末ごとの表示倍率。
- 改行形式が各ゲーム環境で受け入れられるか、本文・タイトルの文字数制限。

ゲーム画像そのものや登場人物の肖像は同梱せず、機能上必要なレイアウトを近似しています。
