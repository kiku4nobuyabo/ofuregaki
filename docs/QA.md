# v0.3 検証記録

検証日：2026-09-29。

## v0.2までに確認済みの基礎動作

PCとスマートフォン実機で、エディタ、4タブ、下書き、マイテンプレ、スタンプ、座標、コピー、保存内容の読込を確認済みです。v0.3はこの動作を維持したまま追加仕様を実装しています。

## v0.3で追加した確認項目

- タイトル上限10文字、本文上限1000文字を設定。
- 文字数表示を `現在値/上限` 形式へ変更。
- 既存の保存データ等から上限超過原稿を読み込んだ場合は警告し、上限超過のままコピー・保存しない。
- 通常のUnicode絵文字を検出し、本文ではゲーム用スタンプへの置換を案内。`{13}` 等のスタンプコードは警告対象外。
- 絵文字を含む原稿のコピー時に確認ダイアログを表示。
- PC／スマホ縦／スマホ横の3プレビュー定義を追加。スマホ縦は約18文字／行、スマホ横は約19文字／行を目安とする。
- 一門共通「戦線・籠城情報」を1件収録。タイトル、日付欄、2戦場×2列の初期形を確認。
- スタンプID 9・35・36の代替絵文字を実機照合結果どおりに修正。コピーする `{ID}` は変更しない。
- v0.1から継続しているlocalStorageキーとスキーマを変更しない。

## 表示確認について

この実行環境ではローカルページをGUIブラウザへ読み込む操作が制限されているため、v0.3生成時の自動ブラウザ操作は実施できませんでした。コード・DOM参照・CSS・自動テストを確認したうえで出力しています。公開前にPC／スマートフォンで、端末別プレビュー切替、絵文字警告、一門共通テンプレを短く確認することを推奨します。

プレビューはゲーム画面の近似です。端末フォント、禁則処理、表示倍率、スタンプ幅などにより折り返し位置が多少異なる場合があります。
